# ReplyFloat AI (v1.5)

AI-powered Android floating smart reply assistant supporting real-time accessibility detection, on-device OCR, multi-model AI fallback chains, and floating overlay controls.

## Features
- **Smart Question Detection**: Instant accessibility node scanning & on-device ML Kit OCR fallback.
- **Dynamic AI Provider Fallback Chain**: Prioritized failover across OpenAI, Gemini, Claude, Ollama, and built-in local heuristics.
- **Floating Overlay Controls**: Quick reply chips with one-tap copy and continuous accessibility stream tracking.
- **Simulator & Diagnostics**: Interactive test benches and diagnostic logging.

## Build Requirements
- Android SDK 35 (minSdk 26)
- JDK 17
- Gradle 8.8.2 / Kotlin 2.0.0
